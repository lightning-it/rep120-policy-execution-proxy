# REP-120 policy execution proxy

This public repository is the secret-free execution boundary for Lightning IT
repository policy. The authoritative policy source is the protected `main`
branch of `lightning-it/shared-assets-lit`. Only reviewed, manifest-bound
generic policy material may be published here under REP-120.

This bootstrap contains no executable workflow, credential, or active consumer
binding. Publication and activation require the protected review, identity
checks, reference pull requests, and canary evidence defined by REP-120.
